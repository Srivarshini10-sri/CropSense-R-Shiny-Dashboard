CropSense: A Regional Crop Yield Dashboard Using R Shiny

 Project Overview

CropSense is an interactive R Shiny dashboard designed to analyze
regional crop yield data.

 Problem Statement

Agricultural data includes crop type, region, soil type, farm area,
rainfall, fertilizer use, and yield. When this information is available
only as a large table, it is difficult to compare crops and regions,
understand the effect of soil, rainfall, and fertilizer on yield, and
identify high- and low-performing farms.

CropSense provides an interactive dashboard that allows users to filter
agricultural data and visualize important crop yield patterns.

Features

- Crop-wise yield analysis
- Region-wise comparison
- Soil type analysis
- Rainfall and fertilizer analysis
- Farm area analysis
- Interactive filters
- Interactive charts and tables
- Identification of high- and low-performing regions

 Technologies Used

- R
- R Shiny
- ggplot2
- dplyr
- Plotly

 How to Run

1. Install R and RStudio.
2. Install the required packages.
3. Open `app.R`.
4. Click **Run App**.
